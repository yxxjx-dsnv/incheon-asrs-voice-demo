# 인천 ASRS · 음성 명령 프로토타입

말하면 로봇이 상자를 가져오는 인천 ASRS 키오스크의 프로토타입입니다. 화면은 실제 키오스크 UI(io_system_ui)를 본떴고,
창고와 로봇은 실제 로봇 치수로 만든 3D 시뮬레이션입니다.

- 음성은 브라우저의 ko-KR 음성 인식으로 **실제로** 알아듣습니다. 미리 녹화된 재생이 아닙니다.
- 알아듣는 것은 빈에 적힌 품목 14가지뿐입니다. 제품 키오스크는 Whisper와 언어 모델로 훨씬 넓은 문장을 해석합니다.
- 실행 전에 창고 상태와 대조하고, 작업자가 **확인**을 누른 뒤에 로봇이 움직입니다. 인식이 불확실하면 추측하지 않고 다시 묻습니다.

## 쓰는 법

Chrome에서 열고 오른쪽 아래 🎙 버튼을 누른 뒤 말하세요. 예: "세차 샴푸 가져와 줘."
음성 인식은 Chrome 계열 브라우저에서만 동작합니다.

```bash
npm install
npm run dev
```

## 구조

- `src/asrsFleet.ts` — 로봇 여러 대의 상태 기계(A* 경로, 엘리베이터, 스테이션에 내려놓고 돌아오기). three.js 없음
- `src/asrsScene.ts`, `src/asrsRobot.ts` — Blender로 만든 GLB 부품을 격자에 배치
- `src/AsrsSim.tsx` — 매 프레임 상태를 메시에 옮겨 그림
- `src/AsrsVoiceDemo.tsx` — 키오스크를 본뜬 화면과 음성 명령
